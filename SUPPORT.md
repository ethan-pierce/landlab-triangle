# Support

Thanks for using landlab-triangle! Here's how to get help.

## Questions and usage help

- Read the [README](README.md) for installation and usage examples.
- See the [Landlab documentation](https://landlab.readthedocs.io/) for the grid
  API that landlab-triangle builds on, and the
  [Triangle documentation](https://www.cs.cmu.edu/~quake/triangle.html) for the
  meshing options.
- If that doesn't answer your question, open a
  [GitHub issue](https://github.com/ethan-pierce/landlab-triangle/issues) with
  the `question` label.

## Bugs and feature requests

Open a [GitHub issue](https://github.com/ethan-pierce/landlab-triangle/issues).
For bugs, please include a minimal example, the `triangle_opts` you used, and
the full traceback.

## Private inquiries

For anything not suited to a public issue, email Ethan Pierce at
<ethan.g.pierce@dartmouth.edu>.
